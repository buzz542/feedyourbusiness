# Legal drafts

Drafts prepared by the build session for the founder to take to a UK solicitor or compliance service (docs/PLAN.md 12.9, F15). None of these is final advice. Sign-off is the founder's.

- `lia.md`: Legitimate Interests Assessment for processing public posts.
- `dpia.md`: Data Protection Impact Assessment, including vendor collection.
- `ropa.md`: Record of processing activities.
- `processors.md`: processors, DPAs and transfer mechanisms.
- `breach-plan.md`: what to do if personal data is exposed.

The public pages (`/privacy`, `/terms`, `/acceptable-use`, `/cookies`, `/sources`, `/remove-my-post`) are drafts too and say so on the page.
