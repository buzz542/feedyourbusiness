# Legal drafts

Drafts for the founder's solicitor or compliance service (docs/PLAN.md 12.9, F15). None of these is
signed off. The public pages (`/privacy`, `/terms`, `/acceptable-use`, `/cookies`) say "Draft for
legal review" until the founder replaces that line after sign-off.

| File             | What it is                                                 |
| ---------------- | ---------------------------------------------------------- |
| `lia.md`         | Legitimate interests assessment for collecting posts       |
| `dpia.md`        | Data protection impact assessment, vendor collection in    |
| `ropa.md`        | Record of processing activities                            |
| `processors.md`  | Processors, DPAs and transfer mechanisms                   |
| `breach-plan.md` | What to do in the first 72 hours of a personal data breach |

Questions for the solicitor are marked **Question** in each file.
