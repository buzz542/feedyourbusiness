# Claims register

Every public marketing claim must be listed here with its evidence before it ships. This is a hard
compliance rule (docs/BRIEF.md, "Marketing and launch"). The `compliance:copy` gate fails the build
if a number appears in marketing pages or emails and is not written somewhere in this file.

## Rules

- Describe what the product does, not outcomes it cannot promise. No "find your first customers in 24 hours".
- Use the exact wording that appears on the site. If the wording changes, change the row.
- No testimonials, review counts, user counts, "as seen on" badges or activity screenshots unless real,
  with written permission, and listed here.
- Example data on the site is labeled "Example" and uses invented handles.
- Do not name competitors in version 1.
- Give each claim an ID made of letters, never numbers (for example `retention-days`), so an ID cannot
  accidentally legitimize a number in copy.
